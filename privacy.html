Privacy policy

Effective 20 October 2026. This policy describes the personal iOS Career Agent utility maintained by the account owner.

Access and purpose

With the owner's consent, the utility uses Gmail read-only access to find and read sent application messages and delivery notices. It uses Google Sheets read-only access to read the owner-selected tracker. Data is used only to reconcile application history, identify duplicate outreach and failed deliveries, and build a private review queue.

Storage and sharing

OAuth credentials are kept in an ignored local file with owner-only permissions, and as encrypted secrets in the owner's private GitHub Actions repository. Local snapshots may contain email bodies and tracker data. Runtime reports may contain business contacts, application statuses, and Gmail message references. Private Actions artifacts are retained for seven days. Initial audit reports remain in the private repository until the owner removes them.

Google provides the APIs and GitHub processes scheduled jobs and private artifacts. This utility does not sell Google user data, use it for advertising, or use it to train general-purpose AI models. This public site contains only application information and policies, not mailbox contents, tracker data, resumes, or credentials.

Control and deletion

The owner can revoke access at Google Account connections, remove repository Actions secrets, and delete local data and private reports. Revocation stops future authorized API access. Existing local copies and private reports must be deleted separately by the owner.

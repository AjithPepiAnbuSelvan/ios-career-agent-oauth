Privacy policy

Effective 21 October 2026. This policy describes the personal iOS Career Agent utility maintained by the account owner.

Access and purpose

With the owner's consent, the utility uses Gmail read-only access to find and read sent application messages and delivery notices. With separately authorized Phase 2 permissions, it can send an exact owner-approved application through Gmail and read/write the owner-selected Google Sheets tracker. Unattended sending is disabled. Data is used to reconcile application history, identify duplicates and failed deliveries, build a private queue, and prepare approved applications. An approved application shares the selected message, contact details and resume with the specified employer; no message is sent without exact application approval.

Storage and sharing

Local OAuth credentials are kept in the encrypted macOS Keychain. The scheduled read-only audit uses encrypted GitHub Actions secrets. The manual sender credential is not installed in scheduled Actions. Local snapshots may contain email bodies and tracker data. Runtime reports may contain business contacts, application statuses, and Gmail message references. Private Actions artifacts are retained for seven days. Initial audit reports remain in the private repository until the owner removes them.

Google provides the APIs and GitHub processes scheduled jobs and private artifacts. This utility does not sell Google user data, use it for advertising, or use it to train general-purpose AI models. This public site contains only application information and policies, not mailbox contents, tracker data, resumes, or credentials.

Control and deletion

The owner can revoke access at Google Account connections, remove repository Actions secrets, and delete local data and private reports. Revocation stops future authorized API access. Existing local copies and private reports must be deleted separately by the owner.

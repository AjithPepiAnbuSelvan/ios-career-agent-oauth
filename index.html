iOS Career Agent

A personal job-search auditing utility maintained by Ajith Pepi Anbu Selvan.

The utility compares an owner-selected Google Sheets tracker with Gmail Sent and delivery notices, then produces a private application review queue. It uses read-only Google access. It does not send emails or submit applications.

Runs take place on the owner's Mac or in the owner's private GitHub Actions repository. It is not offered as a public service, and has no paid subscriptions.

iOS Career Agent

A personal job-search auditing utility maintained by Ajith Pepi Anbu Selvan.

The utility compares an owner-selected Google Sheets tracker with Gmail Sent and delivery notices, then produces a private application review queue. The audit uses read-only Google access. Separately authorized manual application sending uses Gmail send and Sheets write permissions. Each exact application needs owner approval; unattended sending remains disabled.

Runs take place on the owner's Mac or in the owner's private GitHub Actions repository. It is not offered as a public service, and has no paid subscriptions.
